# 3D 网页场景起步项目

这是一个不依赖 npm 的本地 3D 起步项目。

在本文件夹的终端运行：

```powershell
node server.mjs
```

然后在浏览器打开 `http://127.0.0.1:4173`。

拖动页面可旋转模型，滚动鼠标滚轮可缩放。

## 已准备的工具

- Git：用于保存每次改动的历史。
- Node.js 与 npm：npm 已随项目内的便携版 Node.js 准备好，位置在 `../work/node-portable/node-v24.22.1-win-x64/`。

目前的起步页不依赖任何额外安装。后续决定使用 React、Three.js 或内容管理功能时，再安装所需工具即可。
